# IAsyncExternalPreview.AllowAlwaysPreview method

Allows the preview plugin to override the AlwaysPreview setting. Typically useful if plugin's preview does not fully work well with being shown together when the query window appears with results. When AlwaysPreview setting is on and this is set to false, the preview will not be shown when query window appears with results, instead the internal preview will be shown.
