# IPublicAPI.LoadImageAsync method

Load image from path. Support local, remote and data:image url. Support png, jpg, jpeg, gif, bmp, tiff, ico, svg image files. If image path is missing, it will return a missing icon.

```csharp
public ValueTask<ImageSource> LoadImageAsync(string path, bool loadFullImage = false, 
    bool cacheImage = true)
```

| parameter | description |
| --- | --- |
| path | The path of the image. |
| loadFullImage | Load full image or not. |
| cacheImage | Cache the image or not. Cached image will be stored in FL cache. If the image is just used one time, it's better to set this to false. |
