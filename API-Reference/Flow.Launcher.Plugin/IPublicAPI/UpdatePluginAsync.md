# IPublicAPI.UpdatePluginAsync method

Update a plugin to new version, from a zip file. By default will remove the zip file if update is via url, unless it's a local path installation

```csharp
public Task<bool> UpdatePluginAsync(PluginMetadata pluginMetadata, UserPlugin plugin, 
    string zipFilePath)
```

| parameter | description |
| --- | --- |
| pluginMetadata | The metadata of the old plugin to update |
| plugin | The new plugin to update |
| zipFilePath | Path to the zip file containing the plugin. It will be unzipped to the temporary directory, removed and installed. |

## Return Value

True if the plugin is updated successfully, false otherwise.
