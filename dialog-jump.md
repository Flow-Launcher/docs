### Dialog Jump

Dialog Jump lets you quickly navigate Windows Open/Save As dialogs to a folder, without manually browsing.

#### Jump to File Explorer's path
With an Open/Save As dialog focused, press `Alt+G` and it will "jump" to the path shown in the most recently active File Explorer window.

#### Jump by searching
In Settings > General, expand Dialog Jump and enable "Show Dialog Jump Window". This opens Flow's search window whenever an Open/Save As dialog appears, so you can search for a file or folder. Press Enter on a result to jump to its folder, or fill in the file name box if the result is a file.
